# OpenPath — Find Your First Open Source Contribution

OpenPath helps CS students find real, beginner-friendly GitHub issues matched to their skill level — and uses AI to explain exactly what each issue involves and what you'll learn by fixing it.

## The problem
Every CS student has heard "go contribute to open source," opened GitHub, and had no idea where to start. OpenPath turns that vague advice into an actionable next step.

## How it works
1. Pick a language and difficulty level
2. OpenPath pulls real, live issues from GitHub labeled `good first issue` / `help wanted`
3. Click "Explain" on any issue — Gemini AI breaks down what the issue is asking for, why it's beginner-friendly, and what skills you'll gain by solving it

## Features
- Live issue search across multiple languages, powered by the GitHub Search API
- AI-generated, plain-English explanations for any issue (Gemini API)
- Save issues to revisit later
- Real repos, real issues, real maintainers — no fake data

## Tech stack
Node.js · Express · GitHub REST API · Gemini API

## Why it matters
GSSOC alone has 50,000+ applicants every year who hit this exact wall. OpenPath is built for the moment between "I want to contribute" and "I don't know where to start."
